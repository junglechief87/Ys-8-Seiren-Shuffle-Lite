# Seiren-Shuffle-An-Ys-8-Randomizer-
*This is for the Steam release of Ys 8 only*

Ys 8 is a game about an adventurer, Adol, who gets stranded on the deserted Island of Seiren after a shipwreck and must escape while solving the island's many mysteries. Over the course of the adventure Adol must also find other castaways who got stranded from the same shipwreck and this is where the rando kicks off. The rando starts after the game's prologue and plops Adol right into the heart of Castaway Village, the home base of the survivors on the deserted Island of Seiren. So now it's time to begin exploring and discovering what this island is and find a way to escape it. Let's get into how to set this up.

## Installation
This tool is intended for the AP release of the Ys 8 Rando Seiren Shuffle. It's used to patch your expecutable from the file output by Ys 8 AP world and prepare your game for use with the randomizer.
1. Download Seiren Shuffle Lite.
2. Run it and select Browse under "Ys 8 Executable Location" and navigate to the location of your Ys 8 Steam install, select the executable.
3. Click "Patch Files" (This only needs ran once the first time you run the randomizer or if there are new updates to the game's script files for the Rando).
4. Select your .apdana file that the AP world should have output using the Browse under "AP Patch File". 
5. Click "Generate Seed".
6. The game should now be ready to run. It's important to not have the game running while patchings. Certain files that are edited by the patcher are loaded into the game's memory on startup so patching while the game is running won't cause explicit errors but it will cause parts of the patch to not be loaded. 

The "Seiren Shuffle.exe" can sometimes flag as a virus by windows defender, it's a false positive. This is a known issue with pyinstaller's single ".exe" compiles.
